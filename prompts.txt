Chronobot — Session Prompt
==========================

Working on Chronobot — a TypeScript/Node.js Discord scheduled-message bot used
as a portfolio project for Summer 2027 SWE internship applications. The stack is
BullMQ (Redis) for delayed-job execution, PostgreSQL via Prisma for persistence,
prom-client for Prometheus metrics, multi-stage Docker, and GitHub Actions CI.

Current state (as of 2026-06-01):
- All phases complete: PR0 (TypeScript), PR1 (Postgres/Prisma), PR2 (BullMQ worker),
  PR3A (idempotency + DEAD status), PR3B (Prometheus metrics), PR3C (Docker + CI)
- Post-PR3 features also shipped: /timezone set command (DST-safe via dayjs.tz),
  DEAD-job channel notifications, /list stale-time filtering, attachment URL expiry
  warning, Discord 2000-char content guard, 30s worker drain timeout on shutdown
- 248 Vitest unit tests across 19 test files; zero real I/O (all mocked)
